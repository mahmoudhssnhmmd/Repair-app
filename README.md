# HomeFix

**Uber for home services.** A two-sided marketplace connecting customers who need home repairs (plumbing, electrical, appliances, etc.) with verified local workers.

## What it does

- **Customers** browse service categories, view worker profiles (past work, reviews, hourly rate), and request a job with the worker they choose.
- **Workers** sign up with verification info, list their services and rate, and receive/accept job offers from nearby customers.
- Both sides can track job status, leave/receive reviews, and view balance/earnings.
